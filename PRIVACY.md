# Privacy Policy - AragSoft Security

## Overview

AragSoft Security is a GitHub Action designed to help developers identify security issues in their repositories.

## Data Collection

AragSoft Security does not collect, store, or transmit personal information, source code, repository contents, secrets, or user credentials.

## Data Processing

All security scans run inside the user's own GitHub Actions runner environment.

Generated reports remain within the user's GitHub workflow environment unless the user explicitly configures artifact uploads or external integrations.

## Third-Party Tools

AragSoft Security may use open-source security tools including:

- Gitleaks
- OSV-Scanner
- Semgrep
- Trivy
- Syft
- GitHub CodeQL

These tools run as part of the user's workflow.

## Security

Users should configure GitHub Actions permissions following GitHub security best practices.

## Contact

For security concerns, please open an issue or security report in the GitHub repository.
